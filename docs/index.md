# Facet Browser
{: .fs-9 }

A Facets-style media library browser for **64-bit foobar2000 2.x**, with **dark mode**.
{: .fs-6 .fw-300 }

[Download](https://github.com/faljanubi/facet-browser/releases/latest){: .btn .btn-primary .fs-5 .mb-4 .mb-md-0 .mr-2 }
[Install guide](installation){: .btn .fs-5 .mb-4 .mb-md-0 }

![Facet Browser in foobar2000's dark mode]({{ '/screenshots/dark.png' | relative_url }})

Music in the screenshot: Creative Commons albums from the Internet Archive ([credits](screenshots/CREDITS)).
{: .fs-2 .text-grey-dk-000 }

Facet Browser lets you browse your library in **linked panes**. Pick a genre in the first pane
and the next pane shows only the artists in that genre. Pick an artist and the next pane shows
only their albums. Then play the result, or send it to a playlist.

It works like *Facets* by Frank Bicking (2007–2011). Facets was only released for 32-bit
foobar2000 and doesn't support dark mode. Facet Browser runs natively in 64-bit foobar2000 and
follows its dark mode and colour scheme. It is an independent reimplementation and contains no
code from Facets.

## Highlights

- **Linked panes** with multi-select and OR / AND logic
- **Folder column** to browse your folder tree, one level per pane
- **Columns from title formatting**, with multi-value tags split into separate entries
- **19 statistics** such as duration, bitrate, play count, rating, size and dates, all sortable
- **Album art grid** with bottom, right or no labels
- **Toolbar** with source, saved filters, search with history, and a one-click action
- **Send to playlists or autoplaylists**, drag and drop, and the normal foobar2000 track menu
